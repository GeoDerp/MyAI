# Security

We take security seriously. If you discover a security vulnerability, please follow these steps:

1. Create a private issue (or contact the maintainers) describing the vulnerability.
2. Include steps to reproduce, affected versions, and suggested mitigations.
3. Avoid disclosing the vulnerability publicly until it has been addressed.

Dependency updates
- Keep dependencies up-to-date and run `pip list --outdated` or use dependabot.

Reporting
- If you need a private contact for reporting, open an issue labeled `security` and maintainers will respond with next steps.
