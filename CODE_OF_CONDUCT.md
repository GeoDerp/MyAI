# Code of Conduct

This project follows a contributor-friendly Code of Conduct adapted from common open-source guidelines.

Expected behavior
- Be respectful and considerate in discussions and reviews.
- Focus feedback on code and behavior, not on individuals.
- Be open to review and iterate on feedback.

Unacceptable behavior
- Harassment, hateful or abusive language, or discrimination of any kind.
- Threats or encouraging illegal activity.

Enforcement
- Report incidents to the project maintainers via the issue tracker or the repository contact. Maintainers will respond and may take action, including removal of offending content or banning contributors from the project.
